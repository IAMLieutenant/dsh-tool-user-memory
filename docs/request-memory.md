# 从消息添加用户记忆

适用于 0.4.2。

在支持回答操作插槽的 DSH 中，点击回答下方 **记住**，填写名称、调整要保存的个人偏好，再点 **保存**。只有替换同名旧内容时才需要核对新旧对照。

来源折叠在“来源”里，用户消息与助手回复分别标记。来源匹配说明原文存在，不保证内容正确；保存由用户决定。

正常流程只保存用户记忆，没有范围选择。项目事实、任务进度与摘要不放入用户记忆。

消息窗口限定插件运行期间观察到的最近文本：最多 100 个会话，每个最近 20 条，每条前 12000 字；保存的引用最多 2000 字。不读取推理、不扫描全部历史。旧消息不在窗口时，可在记忆列表手动新增。

之前的请求诊断实现仅保留在旧接口兼容路径，正常页面和模型工具不提供它，正常运行也不新增请求记录。旧记录不会自动删除。

验证范围见 [开发与验证](development.md)。
