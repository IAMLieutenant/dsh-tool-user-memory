# 开发与验证

本文对应 2026-10-22 的 0.4.2 版本。

## 构建

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run build
dsh plugin --profile web add "link:/absolute/path/dsh-tool-user-memory"
```

安装或构建后重启 DSH。使用独立 DSH_HOME 和演示数据验证。

## 自动化覆盖

存储、历史、归档、导入导出、项目映射与撤销保留原有回归。旧项目功能的测试通过不代表当前正常流程仍启用这些功能。

## 界面与实际请求

在 Windows、官方 DSH 0.2.1-rc.2 内核、独立测试 profile 和 Chrome 中验收。演示适配器使用固定回复，不调用真实模型服务。

页面检查包括：三个入口、单行空状态、用户记忆新增编辑删除、开关持久化、候选一次保存、替换对照、来源选取、DSH 深浅配色与 420px 布局。备份迁移的 HTML 与操作代码逐字核对保留，并验证导出及导入。

另核对新建会话实际发送给适配器的系统消息：启用时包含保存的个人偏好，停用及删除后排除，不附带旧项目索引。这证明组装结果，不证明真实模型每次都会遵循。

README 图片使用隔离演示数据，不是用户实际项目内容。

自动记录另覆盖固定类别与项目/流程排除、当前用户原话核验、去重、防重复写入、单次撤销和后续修改保护，以及本机同源撤销接口。正常模型新增受限自动记录工具，不新增后台提取模型。
